# Abzal Uteshov — Landing Page

Официальный одностраничный сайт артиста Абзала Утешова. Один файл
`index.html` — разметка, стили и скрипты собраны вместе, без сборки и
зависимостей. Открывается прямо из файла или деплоится на любой
статический хостинг.

## Структура проекта

```
index.html   — вся страница: разметка, <style> и <script> инлайн
assets/img/  — изображения (фото артиста, логотип, favicon, OG-обложка)
robots.txt, sitemap.xml — индексация поисковиками
.htaccess, .nginx.conf  — кэширование и сжатие на стороне сервера
```

## Как запустить локально

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Либо просто откройте `index.html` в браузере.

## Что где искать в index.html

- **Hero** (`#hero`) — фото артиста на красном фоне, заголовок-логотип,
  кнопка «Купить билеты», соцсети
- **Тур** (`#tour`) — таймер до ближайшего концерта и список дат со
  ссылками на 2GIS (адрес зала) и билетного оператора. Чтобы добавить
  город — скопируйте `<li class="tour-item fade-in">…</li>`. Статусы:
  `is-sold-out` (продано) и `is-coming-soon` (билеты скоро)
- **Музыка** (`#music`) — Spotify-плеер, ссылки на Apple Music/Яндекс
  Музыку, карусель клипов
- **FAQ + Контакты** (`#faq`) — вопросы по билетам и два блока букинга
  (на русском и казахском)
- **Аналитика** — закомментированные шаблоны Google Analytics,
  Яндекс.Метрики, Facebook Pixel и TikTok Pixel в `<head>`; клики по
  «Купить билеты» уже готовы отслеживаться (`data-track="buy-tickets"`)
  как только счётчики подключат

## Деплой

Пушится в `main` — раздаётся статикой (Plesk/nginx/Apache/GitHub Pages),
сборка не требуется.
