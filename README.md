# Abzal Uteshov — Landing Page

Официальный одностраничный сайт артиста Абзала Утешова. Верстка на чистом HTML/CSS/JS, без сборки и зависимостей — открывается прямо из `index.html` или деплоится на любой статический хостинг (GitHub Pages, Netlify, Vercel).

## Структура проекта

```
index.html            — вся разметка страницы (Hero, Тур, Музыка, FAQ, Контакты)
assets/css/style.css  — стили, тёмная тема, mobile-first
assets/js/main.js     — мобильное меню, fade-in анимации, шапка при скролле, аналитика
assets/img/           — изображения (добавьте сюда фото артиста)
```

## Как запустить локально

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Что нужно доделать перед запуском

1. **Фото/видео артиста** — Hero-блок использует реальное фото
   (`assets/img/hero-artist.webp`, вырезано на прозрачном фоне) поверх
   фонового изображения из афиши артиста (`assets/img/hero-bg.webp`).
   Заголовок — не текст, а картинка `assets/img/hero-title.webp`
   (стилизованный логотип «Abzal Uteshov»). Оттуда же автоматически
   сгенерированы `assets/img/favicon.png` (из `logo.webp`) и
   `assets/img/og-cover.jpg` (обложка для соцсетей). При необходимости
   зацикленное видео можно подключить через `<video>` вместо `<img>`
   (структура `.hero-media` в CSS уже поддерживает абсолютное
   позиционирование слоёв).
2. **Логотип** — `assets/img/logo.webp` используется как иконка сайта
   (favicon) и в шапке (`.logo-img`) вместо текста «ABZAL UTESHOV».
3. **График тура** — блок `#tour` в `index.html` заполнен реальными
   датами (Қызылорда — Алматы, 5–26 сентября) со ссылками на 2GIS
   (выделены зелёным, с иконкой геометки, чтобы их точно заметили) и
   билетного оператора (sxodim.com / almaty-ayenderi.kz). Чтобы добавить
   новый город — скопируйте `<li class="tour-item fade-in">…</li>`. Для
   статуса «Продано» добавьте класс `is-sold-out` и замените кнопку на
   `<button class="btn btn-disabled tour-btn" disabled>Продано</button>`,
   для «Скоро» — класс `is-coming-soon` и кнопку с текстом «Скоро».
4. **Клипы и стриминги** — блок `#music` показывает 3 клипа в виде
   свайп-карусели (`.clips-carousel`) с превью YouTube и плеем по клику
   (клип грузится в iframe только после клика — легче для мобильного
   интернета), ниже — встроенный Spotify-плеер (`.spotify-player`
   iframe) и кнопки Apple Music / Яндекс Музыка на реальные страницы
   артиста.
5. **Контакты (Booking)** — блок `#booking` уже указывает на менеджера
   Маруфа (WhatsApp). Вопросы по билетам в FAQ ведут на WhatsApp Акжола
   с заранее заполненным сообщением.
6. **Соцсети** — Instagram, TikTok, YouTube, Telegram и Spotify в
   шапке/Hero/footer уже ведут на реальные страницы артиста.
7. **Аналитика** — по решению заказчика пока не подключается (нет готовых
   SEO-метаданных). В `<head>` `index.html` остаются закомментированные
   шаблоны для Google Analytics, Яндекс.Метрики, Facebook Pixel и TikTok
   Pixel — вставьте ID и раскомментируйте нужные блоки, когда будет решено
   подключать. Клики по кнопке «Купить билеты» уже готовы отслеживаться
   через `assets/js/main.js` (`data-track="buy-tickets"`), как только
   счётчики появятся на странице.

## Деплой

Статику можно выложить на GitHub Pages (Settings → Pages → Deploy from
branch), Netlify или Vercel — специальная сборка не требуется.
